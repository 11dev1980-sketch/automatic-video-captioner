# Unit Economics

## Unit Economics Philosophy

### Core Principle: **Spiritual Return on Investment**
We measure success not just in financial terms, but in spiritual impact. Every dollar invested must generate both financial returns and spiritual value for our users and communities.

### Key Metrics Overview
- **CAC (Customer Acquisition Cost)**: Cost to acquire one user
- **CLV (Customer Lifetime Value)**: Total revenue from one user
- **LTV:CAC Ratio**: Efficiency of customer acquisition
- **Payback Period**: Time to recover acquisition costs
- **Spiritual ROI**: Impact on users' spiritual journey

## Customer Lifetime Value (CLV) Analysis

### CLV Calculation Model

#### **Basic Formula**
```
CLV = (Average Revenue Per User × Gross Margin × Customer Lifetime) - CAC
```

#### **Detailed Breakdown**

**Free User CLV**:
```
Average Revenue Per User: $0.50/month (from marketplace commissions)
Gross Margin: 80%
Customer Lifetime: 18 months
CLV = ($0.50 × 0.80 × 18) - $15.00 = -$7.80

Note: Free users have negative direct CLV but positive indirect value through:
- Community building
- Word-of-mouth marketing
- Premium conversion potential
- Content creation contributions
```

**Premium User CLV**:
```
Average Revenue Per User: $9.99/month
Gross Margin: 85%
Customer Lifetime: 24 months
CLV = ($9.99 × 0.85 × 24) - $25.00 = $178.36
```

**B2B Customer CLV**:
```
Average Revenue Per Customer: $100/month
Gross Margin: 90%
Customer Lifetime: 36 months
CLV = ($100 × 0.90 × 36) - $500.00 = $2,740.00
```

### CLV Enhancement Strategy

#### **Free User CLV Enhancement**

#### **Premium User Payback**

Payback Period: 25.00 ÷ 8.49 = 2.94 months
```

#### **B2B Customer Payback**
```
Monthly Net Revenue: $41.65 (mosque package)
Initial CAC Investment: $500.00
Payback Period: 500.00 ÷ 41.65 = 12.00 months

## Sensitivity Analysis

### Key Variable Sensitivity

#### **CAC Sensitivity**
```
CAC Increase 20%: Payback increases 20%
CAC Decrease 20%: Payback decreases 20%
CAC Increase 50%: Business model becomes unprofitable
CAC Decrease 50%: Significant improvement in profitability
```

#### **Retention Sensitivity**
```
Retention Increase 10%: CLV increases 15-20%
Retention Decrease 10%: CLV decreases 15-20%
Retention Increase 20%: LTV:CAC ratio improves significantly
Retention Decrease 20%: Business model becomes marginal
```

#### **Revenue Per User Sensitivity**
```
ARPU Increase 10%: Break-even reduces by 10%
ARPU Decrease 10%: Break-even increases by 10%
ARPU Increase 25%: Significant improvement in unit economics
ARPU Decrease 25%: Business becomes unprofitable
```
